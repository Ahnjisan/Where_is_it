# 어디갔지 Where is it 요구사항

## 서비스 정의와 해결하려는 문제

Where is it은 한국에서 물건을 잃어버린 외국인이 자신의 언어로 분실물의 특징과 분실 시기·장소를 설명하면, AI가 경찰청 검색조건으로 구조화하고 경찰청 습득물정보 조회 API의 실제 후보를 보여주는 서비스입니다. 한국어 검색조건을 만들고 습득물 정보를 확인하기 어려운 사용자를 돕습니다.

## 핵심 사용자

한국에서 물건을 잃어버린 외국인입니다. 지원 언어의 범위는 아직 정하지 않았습니다.

## 핵심 사용자 흐름

1. 사용자가 지원 언어로 분실물 특징, 분실 시기와 장소를 입력합니다.
2. AI가 물품 분류, 색상, 기간, 지역 등의 조건을 구조화하고 경찰청 검색에 사용할 한국어 기준으로 변환합니다.
3. 경찰청 습득물정보 조회 API로 실제 후보를 조회합니다.
4. 조회된 후보와 사용자 설명을 비교해 우선순위와 추천 이유를 사용자 언어로 제공합니다.
5. 사용자가 후보 목록과 사진, 습득 장소, 보관기관을 포함한 상세정보를 확인합니다.
6. 원하는 후보가 없으면 검색조건을 추적 대상으로 등록합니다.
7. 등록 후 7일 동안 하루 1회 동일 조건으로 재검색합니다. 새 유사 후보를 발견하면 그 건수를 포함해 이메일로 알립니다.
8. 등록 후 7일이 지나면 추적을 자동 종료합니다.

## 핵심 기능 범위

- 다국어 자연어 입력과 AI 기반 검색조건 구조화
- 경찰청 습득물정보 조회 API 기반 후보 조회
- AI 기반 후보 우선순위와 사용자 언어로 된 추천 이유
- 후보 목록 및 사진·습득 장소·보관기관 상세정보 확인
- 분실물 추적 등록, 목록·상세 조회, 정보 수정, 등록 삭제
- 7일간 하루 1회 재검색, 신규 유사 후보 이메일 알림, 기간 종료

## AI 활용 원칙

AI는 경찰청 API가 실제로 반환한 후보만 대상으로 우선순위와 추천 이유를 생성합니다. 존재하지 않는 습득물 후보를 만들어서는 안 됩니다.

## 추적 등록정보 CRUD

| 작업 | 범위 |
| --- | --- |
| Create | 분실물 검색조건과 추적 정보 등록 |
| Read | 추적 목록과 상세정보 조회 |
| Update | 분실물 설명, 검색조건과 이메일 정보 수정 |
| Delete | 추적 등록 삭제 |

## 데이터 활용 방향

경찰청 습득물정보 조회 API에서 물품명, 물품 분류, 색상, 습득일자, 습득장소, 보관장소 또는 보관기관, 사진, 상세설명을 후보 확인과 비교에 활용합니다. 세부 API 계약과 일부 데이터베이스 구조는 별도 명세와 Issue에서 확정할 수 있습니다.

## 식별자 표기 규칙

- 업무 용어와 ERD 논리명은 한글을 사용하며, 한글은 문서 설명과 Database COMMENT에도 사용할 수 있습니다.
- MySQL 테이블·컬럼·제약조건·인덱스 물리명은 소문자 영문 `snake_case`를 사용합니다.
- Java 클래스명은 영문 `PascalCase`, Java 필드명과 API JSON 필드명은 영문 `camelCase`를 사용합니다.
- Enum 값은 영문 `UPPER_SNAKE_CASE`를 사용합니다.
- 제약조건과 인덱스 이름은 `pk_`, `fk_`, `uk_`, `idx_`, `chk_` 접두어를 사용합니다.
- 이해하기 어려운 축약어와 MySQL 예약어 충돌을 피하고, 플랫폼별 대소문자 차이를 방지하기 위해 영문 물리명은 소문자로 통일합니다.

## 제외 범위

- 사진만으로 동일 물품을 자동 판별하거나 실제 소유자를 판정하는 기능
- 경찰 신고 또는 반환 신청 대행, 경찰청 시스템의 데이터 등록·수정
- 7일 초과 장기 추적 또는 실시간 상시 API 감시
- 모든 언어 지원

## 완료 판단 기준

- 사용자의 설명에서 구조화한 조건으로 경찰청의 실제 습득물 후보를 조회하고, 그 후보에 한정해 추천 이유를 제시할 수 있습니다.
- 후보의 사진·습득 장소·보관기관을 확인하고 추적 등록정보를 생성·조회·수정·삭제할 수 있습니다.
- 등록 후 7일 동안 하루 1회 재검색하고 새 유사 후보의 건수를 포함해 이메일로 알리며, 기간 종료 후 추적을 자동 종료합니다.

식별자 표기 규칙은 위 기준으로 확정합니다. 구현 방법, 테스트 케이스, 세부 API 계약과 데이터베이스 전체 구조는 별도 설계에서 정합니다.
